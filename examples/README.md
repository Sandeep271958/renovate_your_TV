# Examples: Sony Bravia KD-49X8200E

This folder contains the tested debloat list and launcher configuration specifically tailored for the **Sony Bravia KD-49X8200E** (2017, Android TV 8/9, MediaTek MT5891, BRAVIA_ATV2 platform).

| Folder | TV Model | Platform / OS | Status |
|---|---|---|---|
| [`sony-kd-49x8200e/`](sony-kd-49x8200e/) | Sony Bravia KD-49X8200E | BRAVIA_ATV2 (MediaTek MT5891) / Android TV 8/9 | Fully Configured & Tested |

## Files in `sony-kd-49x8200e/`

- **`debloat.txt`**: Complete list of telemetry, ads, Samba TV ACR tracker, demo, and unneeded bloatware packages to safely disable.
- **`config.json`**: Pre-configured settings (dock apps, hidden apps, Sony live TV input package `com.sony.dtv.tvx`, and Sony remote app key scancodes).
- **`tv.json`**: Device profile metadata.
- **`README.md`**: Model-specific notes and quick run instructions.
